# Иврит — учебная платформа

Личный набор инструментов для изучения иврита. Онлайн-версия (GitHub Pages):

- **Разбор текстов** (`razbor/`) — чтение с пословным подстрочником: огласовки, транслит, перевод, корень, биньян; практика; добавление слов в словарь.
- **Интерактивный словарь** (`slovar/`) — словарь-тренажёр с интервальным повторением, квизами и озвучкой.
- **Гайд по биньянам** (`guide/`) — семья биньянов, конструктор слова из корня, определитель биньяна по форме, грамматические таблицы.

## Добавить новый текст в «Разбор»

Тексты лежат в `razbor/texts/` в виде `.json` и перечислены в `razbor/texts/index.json`.
Чтобы добавить текст: положить новый `*.json` в `razbor/texts/`, дописать его имя в `index.json`, закоммитить. Он появится у всех автоматически.

Формат разбора можно посмотреть в самом модуле: «＋ Новый текст» → «Показать формат».

## Что не входит в онлайн-версию

Видеоуроки, SVG-слайды и аудио оригинального курса не публикуются (объём превышает лимиты GitHub Pages, плюс это сторонний защищённый авторским правом материал). Они остаются в локальной версии проекта.

## Локальный запуск

Открыть `index.html` через локальный веб-сервер (например, `python -m http.server`), а не двойным кликом — иначе часть функций (загрузка данных) заблокируется браузером.
